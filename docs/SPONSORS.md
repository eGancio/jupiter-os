# Sponsors & Funding Transparency

JupiterOS is **free and open-source** (AGPL-3.0) and intends to stay that way.
This document explains exactly how the project is funded — no surprises, no fine print.

## How JupiterOS is funded

The project is sustained by two things, and only two:

1. **Disclosed integration referrals** — when Jupiter helps you connect a third-party
   service it genuinely integrates with (e.g. an automation platform), we may earn a
   referral commission. **It never costs you more.**
2. **Professional services** — custom development and support for organisations that
   need more than the open tool provides.

**Never:** telemetry, selling your data, ads, or paywalling core features.
No venture capital, so no pressure to ever change that.

## Our promises

- **No biased recommendations.** Jupiter's suggestions are *not* ranked by who pays us.
  The logic is in the source code — read it, grep it, verify it.
- **Infrastructure, not advice.** Referrals only ever apply to services you were going
  to use anyway. Jupiter does not push products to earn a commission.
- **Always disclosed inline.** If a suggestion carries a referral, you'll see it labelled.
- **You can turn it off.** Disable all referral suggestions in Settings → Privacy.
- **Attribution happens at the partner's side** (a referral link), **never by tracking
  you inside the app.** Zero-telemetry still holds, with no exceptions.
- **You can remove it entirely.** It's AGPL — fork it and strip every referral line.
